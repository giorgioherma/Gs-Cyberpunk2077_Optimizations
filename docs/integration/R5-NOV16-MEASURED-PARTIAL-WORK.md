## Spatial source contract and dangerous equivalence gap

`r6/scripts/ReinforcementsSystem/ReinforcementSystem.reds` initializes exactly **37** `SquareArea` literals in `OnPlayerAttach`, then iterates `this.restrictedCordinates` and calls `IsPointInQuad(p, area)` at line 599. The uploaded 2,319-source snapshot contains four lexical mentions of `restrictedCordinates` in that single source file and no other lexical occurrences, **not** proof against aliases/native/public member mutation. Every 37 initial literal quads has two non-zero-area triangles after angle sorting; the smallest double triangle area in a source-only double-precision audit is **144 square-coordinate units**. This says nothing about later game state.

`Utils.reds` `SortSquare` (line 216) is called before every geometry test; its two `AtanF` sites together recorded **2,592,072 direct calls**. The already existing **`ANGLE_SORT_INVARIANT_V1` preview** addresses a small loop-invariant subexpression (12 → 9 angle evaluations per sort), **not** the cost of repeated polygon preparation or its full elimination. Do not build a second corrective pass over its generated output.

**Do not implement an unconditional AABB early-return yet.** The original `PointInTriangle` returns `!(hasNeg && hasPos)` from signed cross products; for a degenerate collinear triangle with an outside collinear point all signs can be zero and the original can return `true`, whereas an AABB check returns `false`. Nonfinite/overflow and boundary Float behavior also require an exact equivalence proof. A future generic prefilter must preserve original behavior in every admitted state, including mutable/partial installations. If proof requires instrumentation, ask for only the minimal bounded outside/inside outcome counter after exhausting current evidence; the existing F11 capture does **not** report AABB hit rates.

**No first optimization admitted yet.** Conservative next order is: (1) generic-safe spatial negative-test proof with original geometry fallback and all numeric states, (2) UI structural-versus-time inputs / widget-generation evidence, (3) input-device/event admission only if Lua effects and listener entries can be verified, (4) diagnostic settings-change epoch only if the exact publisher is available. The original fact-subscriber graph remains valid for partial use inside all of these methods; it does not authorize rewriting their entire cycles.
