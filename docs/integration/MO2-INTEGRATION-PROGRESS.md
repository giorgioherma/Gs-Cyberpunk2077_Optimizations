## 2026-11-23 — Stage 3 source-owner overlay builder: REAL MANAGER PROOF for no-0-Engine original

**Implementation:** `src/GTotalOptimizer.Core/Mo2ProfilerOverlayBuilder.cs` projects the selected MO2 profile's effective **CET ASI, bindings.json, and CET mod sources** into a private, disposable game-shaped fixture. It does not run either owner installer against the live game or modify any MO2 mod. It invokes the **existing packaged CET and GRSP manager executables** through GCO `ComponentCommandRunner` only after `ComponentBundleVerifier` validates both managers and payloads. All original source hashes are checked again after the installers finish. The builder derives the **actual changed-file delta**, copies only approved native ASI, CET 0-Engine worker, CET controls/bindings, GRSP DLL/data files to `%LOCALAPPDATA%/GCO/MO2Bridge/staging/<session>`, verifies their hashes, and writes a durable private session journal **before** the first write. Any unexpected owner edit, deleted user file that a VFS overlay cannot represent, stale source or malformed owner output fails closed with `recovery-required` evidence. A virtual override cannot delete files, so source-owner deletions are explicitly refused.

**Authoritative input fix:** `Mo2SourceInspector.IndexLayer` now includes the actual **selected-profile winning CET `bindings.json`** alongside native ASI and CET Lua. Without this, the owner installer would treat a user's profile-bound CET keys as missing and could author the wrong F11 overlay. The MO2 Python mapper allowlist is aligned with real owner outputs, including `bindings.json`, `CETProfilerControls/CaptureTitle.txt` and `0-Engine/modules/G-CET/Scheduler.lua`, while rejecting arbitrary sibling scheduler modules.
